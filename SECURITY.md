# Security Policy

## Supported Versions

jumux is a CLI tool distributed via `go install`, Homebrew, and OS packages.
Only the latest released version is supported with security fixes.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, email richmcase@gmail.com with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- Any relevant logs, config, or environment details

We'll acknowledge your report and aim to provide a fix or mitigation as soon
as possible.
